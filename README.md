# Pani Puri Game

A light and fun browser game inspired by the Indian street food favorite: Pani Puri.

## How to play

1. Open the app in your browser.
2. Fill the plate with ingredients for the customer's order.
3. Click the "Serve Pani Puri" button.
4. Match the exact order to earn points.
5. Keep the combo alive before the timer hits zero.

## Run locally

Because this is a static app, you can launch it with any simple local server:

```bash
cd pani-puri-game
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features

- Fast-paced street food mini-game
- Random customer orders
- Score, timer, combo, and lives
- Responsive layout for desktop and mobile

## Project structure

- `index.html` — app layout
- `styles.css` — visual design and responsive styling
- `script.js` — gameplay logic
